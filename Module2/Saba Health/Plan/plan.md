# Saba Health

## Project Description 

Saba Health is a responsive wellness information webiste designed to help users discover and save simple health and wellness tips.

The website is designed as a mobile first and users Javascript to load, filter, render and persist health information

## Must Have

- Load Health tips from a local JSON file
- Render health tips dynamically with Javascript
- Search health tips
- Filter health tips by category
- Save health tips to favorite
- Remove health tips from favorites
- Persist favorites with localStorage
- Responsive mobile first layout
- Semantic HTML
- Loading state
- Error state
- Empty search state

### Features

- Health tip details
- Wellness goal form
- Form Validation
- Improved accessibility

## Target User 
A person in Addis Ababa who wants simple accesible, feneral wellness information.
